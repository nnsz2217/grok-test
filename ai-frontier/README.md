## 以后怎么加笔记

1. 一条已经核对过的动态一篇，文件名带上日期（`YYYY-MM-DD-主题`）。同一件事的后续更新合并进原文件，并改更新时间。
2. 文末按 [笔记约定](../resources/conventions.md) 写来源链接、更新时间（Asia/Shanghai）和信息可信度。数字、发布日期和可用性都要对得上来源。
3. 回到本页「当前内容」，加上相对链接、日期和一句话，并更新本页的更新时间。条目多了以后按时间倒序排。
4. 通过 Pull Request 合并，不要直接推送到 `main`。
