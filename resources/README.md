## 当前内容

- [笔记约定](conventions.md)

  规定以后每篇笔记都要带来源链接、更新时间（Asia/Shanghai）和信息可信度；适用时再写平台、技能门槛，以及免费 / 付费 / API 费用。本页是约定，不是对外部产品的研究。

本目录还没有官方文档汇编或教程目录。

## 以后怎么加笔记

1. 一份跨分类的资料或一份全库约定写成一篇。已有文件能覆盖时，更新原文件。
2. 文末按 [笔记约定](conventions.md) 写来源链接、更新时间（Asia/Shanghai）和信息可信度。外部文档只收录核对过的链接，不复制长文。
3. 回到本页「当前内容」，加上相对链接和一两句这篇是什么，并更新本页的更新时间。
4. 通过 Pull Request 合并，不要直接推送到 `main`。
