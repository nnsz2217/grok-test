# 用 Google 快讯邮件跟踪课程、奖学金或论文更新

本篇只使用一条已能对照官方帮助核对的路径：打开 Google 快讯页面、创建快讯，当 Google 搜索出现与主题相关的新结果时，由系统向你的邮箱发邮件。不涉及编写代码，也不把未经官方帮助确认的 RSS 或第三方聚合工具写进主流程。

## 正文

### 主路径（唯一推荐入口）

请只走下面这一条官方入口，不要和其它订阅方式混用后再算「已经按本篇做完」：

- 产品入口：[Google 快讯](https://www.google.com/alerts)（`https://www.google.com/alerts`）
- 操作说明：[创建快讯 - Google 搜索帮助](https://support.google.com/websearch/answer/4815696?hl=zh-CN)（[英文原文](https://support.google.com/websearch/answer/4815696?hl=en)）

官方说明是：当 Google 搜索中出现与某个主题相关的新结果时，你会收到电子邮件；例如可获取与新闻、产品或提到你姓名的内容有关的信息。大学生可把「主题」换成课程关键词、奖学金名称、会议或论文相关检索词，用法与官方所述「关注一个主题」相同。

本篇不以 RSS、Outlook 订阅源或其它邮件客户端的订阅功能作为主路径。当前这份《创建快讯》帮助在步骤中写的是「每当我们找到符合条件的搜索结果，便会向您发送电子邮件」，选项里列出的是通知频率、网站类型、语言、地区、结果数量和接收帐户，**没有把 RSS 写进该官方步骤**。因此这里不教 RSS 订阅。

### 能解决什么问题

你不必每天打开搜索引擎、重复输入同一组词，也能知道网上是否出现了与课程、奖学金或论文相关的新公开结果。快讯把「有新的匹配搜索结果」变成一封邮件。它不会替你写研究报告，也不会保证覆盖某一官方网站的全部通知；它只反映 Google 搜索当时找到的、与你设定主题相符的新结果。

### 需要哪些工具

- 一个 Google 帐户，并在浏览器中登录。官方故障排除的第一步就是「检查您登录的是哪个帐户」；管理、修改和停用后重新启用快讯，都在已登录的 Google 快讯页面完成。
- 能接收该 Google 帐户邮件的邮箱。若使用 Gmail，官方建议将 `googlealerts-noreply@google.com` 加入通讯录，以免快讯进垃圾邮件。
- 电脑上的浏览器即可，不需要安装桌面软件，不需要 API Key，也不需要写脚本。

### 触发条件

- **你完成的一次性操作**：在 [Google 快讯](https://www.google.com/alerts) 创建一条（或多条）快讯。这是订阅动作。
- **之后系统何时发信**：官方表述为「每当我们找到符合条件的搜索结果，便会向您发送电子邮件」。也就是说，**没有新的匹配结果时，不会为了「打卡」而每天都寄信**。第一封邮件不一定在创建后立刻到达。发送频率可在「显示选项」里更改，但具体有哪些频率名称，官方帮助只写到「系统向您发送通知的频率」，本篇不编造下拉菜单里的每一项用词。
- 快讯被你删除、在邮件底部取消订阅，或在页面上显示为已停用（需点「启用」）后，不应再按「仍在自动监控」来理解。

### 安装和配置

不需要安装应用程序。配置就是：登录 Google 帐户，打开官方入口并创建快讯。

### 完整工作流程（如何订阅）

请按官方帮助的顺序操作，并加上本篇写明的「怎样算做完」检查。

**第一步：打开官方入口并确认帐户**

1. 在电脑浏览器中登录你要用来收信的那个 Google 帐户。
2. 打开 [https://www.google.com/alerts](https://www.google.com/alerts)。
3. 若页面提示登录，先登录再继续。若你有多个 Google 帐户，先确认右上角是收件用的那一个（官方故障排除把「检查登录的是哪个帐户」列为第一步）。

**第二步：输入要跟踪的主题**

在页面顶部的方框中输入一个主题。建议一次只跟踪一件足够具体的事，例如：

- 某项奖学金的正式名称或常用简称；
- 某门课或某个研究方向里你真正会点开的词（过宽的词如「经济学」「人工智能」可能产生大量不相关邮件，这不是官方禁令，而是使用时需要自己收窄）；
- 某位作者、某篇论文标题或某个会议名称。

官方帮助把这里称为「您想要关注的主题」，没有为奖学金或论文单独列一种创建方式；上面只是把同一官方步骤用到学习场景。本篇也不把未在《创建快讯》帮助中核对过的高级搜索运算符写成必做步骤。

**第三步：用「显示选项」调整设置，然后创建**

1. 点击「显示选项」（英文帮助为 Show options）。按官方帮助，你可以更改：
   - 系统向你发送通知的频率；
   - 通知中显示的网站类型；
   - 你的语言；
   - 你想获取来自世界上哪个地区的信息；
   - 你想获得多少结果；
   - 哪些帐户会收到快讯。
2. 选项的具体标签以当时页面为准。本次打开产品页时，英文界面可见 How often、Sources、Language、Region、How many 等栏目；中文界面用词以你打开的页面为准，不要依照非官方教程臆造菜单路径。
3. 点击「创建快讯」（英文为 Create Alert）。按官方说明，此后每当系统找到符合条件的搜索结果，便会向你发送电子邮件。
4. 需要跟踪多个互不相关的主题时，重复第二步和第三步，各建一条快讯，不要把许多无关词硬塞进同一条。

**第四步：确认列表里已经有这条快讯**

创建后，仍留在 [Google 快讯](https://www.google.com/alerts) 页面，在「我的快讯」中应能看到刚创建的条目。若要修改：在快讯旁边点击「修改」，必要时再点「显示选项」，改完后点击「更新快讯」。若要更改获取快讯的方式，官方步骤是点击「设置」，选中想用的选项，然后保存。若要删除：在快讯旁边点击「删除」；也可以在快讯邮件底部点击「取消订阅」。

**第五步：检查邮箱能收到官方发件地址的信**

1. 打开该 Google 帐户对应的收件箱（若是 Gmail，可打开 [https://mail.google.com/](https://mail.google.com/)）。
2. 按官方故障排除检查：收件箱未满；快讯没有进垃圾邮件文件夹。若使用 Gmail，将 `googlealerts-noreply@google.com` 加入通讯录。
3. 若页面提示快讯已停用，先打开 [Google 快讯](https://www.google.com/alerts)，点击「启用」，再在「我的快讯」中点开该条，用「显示选项」核对邮箱地址和设置。
4. 请记住：官方只保证「找到符合条件的新结果时发邮件」，所以**不能以「创建后 10 分钟内一定收到第一封信」作为成功标准**。若长时间完全没有邮件，再按上面的故障排除逐步查帐户、快讯是否启用、设置中的邮箱，以及垃圾邮件文件夹。

**可选：等收到第一封快讯后，用 Gmail 过滤器加标签（不是主路径的必做项）**

只有在你使用 Gmail，并且已经至少收到一封 Google 快讯邮件之后，才建议做这一步。做法以 [创建用于过滤电子邮件的规则 - Gmail 帮助](https://support.google.com/mail/answer/6579?hl=zh-CN) 为准：

1. 打开 Gmail，选中那封快讯旁边的复选框。
2. 点击「更多操作」，再点击「过滤此类邮件」。
3. 核对过滤条件后，点击「创建过滤器」，选择要执行的操作（官方写明过滤器可用于添加标签，或归档、删除、加注星标、自动转发等），再点击「创建过滤器」。

这样只是把已经在工作的快讯邮件整理到标签下，不代替「创建快讯」本身。本篇不把某一具体标签名或未在该帮助页逐项列出的搜索框字段名写成必填项。

### 是否需要 API Key

不需要。官方创建、修改、删除快讯和故障排除步骤都未要求 API Key。

### 使用成本

官方《创建快讯》帮助和产品页在本次核对中**没有列出收费项目、配额或价目**。创建步骤也不要求付款或填写 API Key。因此本篇费用记为「未知」，不把「免费」写成已核对事实。若日后官方页面出现收费说明，以当时页面为准，并更新本篇日期。

### 技术门槛

不需要编程，也不需要安装桌面自动化软件。需要会登录 Google 帐户、在网页上填写主题并保存，以及在邮箱里查看来信和垃圾邮件文件夹。Gmail 过滤器是可选整理步骤。

### 适用场景

- 想持续关注某项奖学金、公开招生或竞赛信息是否出现新的网页或新闻结果。
- 想跟踪某门课、某个研究方法、某位作者或某个会议的公开新结果。
- 接受「有新的匹配搜索结果才寄信」，并且能用邮箱阅读链接后再自行判断是否值得点开。

不适用：必须监控某个没有被 Google 搜索收录的校内系统或需要登录才能看到的页面；必须精确到「该网站一更新就在几分钟内通知」且不能接受遗漏；需要把结果自动写成研究报告或自动填申请表。

### 潜在限制和安全风险

- **覆盖范围限于 Google 搜索当时找到的匹配结果**，不是某一学校、基金或期刊官网的完整通知源。没有新匹配时不会发信，不能把「今天没邮件」理解成「今天一定没有更新」。
- **主题过宽会收到大量邮件**，主题过窄或用词与网页不一致则可能长期没有邮件。需要时用官方的「修改」调整主题或选项，而不是另装来路不明的监控软件。
- **邮件里的链接仍要谨慎点击**。快讯可能指向第三方网页。不要在陌生链接里填写申请表密码或银行卡信息；重要通知应再回到你已知的官方网站核对。
- **帐户与隐私**：快讯绑定你登录的 Google 帐户和收件邮箱。不要把含个人身份证号、银行账户等敏感信息的字符串设为监控主题。不用的快讯应及时删除或取消订阅。
- **投递问题**：邮件可能进入垃圾邮件文件夹；官方也提到要确认收件箱未满、快讯未被停用、登录的是正确帐户。
- 本篇未在一个已登录的学生邮箱里实际创建快讯并等待来信，完成标准中关于「最终会收到邮件」的部分，依赖官方说明，而不是本次实操记录。

### 怎样算做完

下列五项都成立，才算这条工作流已经订阅到位。只打开过产品页、却没有出现在「我的快讯」里，不算做完。

1. 你已用准备收信的那个 Google 帐户，在浏览器中打开 [https://www.google.com/alerts](https://www.google.com/alerts)，并且能看到「我的快讯」列表。
2. 「我的快讯」中至少有一条你主动创建的快讯，主题是你真正要跟踪的课程、奖学金、论文或其它具体学习主题（不是随便输入后打算马上删除的测试词，除非你已用测试词走通第 4 步后再改成正式主题）。
3. 该快讯已用「显示选项」核对过通知频率、语言、地区、结果数量和接收帐户；接收帐户就是你要检查的那个邮箱。
4. 你已打开该邮箱，将 `googlealerts-noreply@google.com` 加入通讯录（若使用 Gmail，这是官方建议），并知道去垃圾邮件文件夹里查找快讯。你理解：只有系统找到新的匹配结果才会发信，因此「创建后立刻收到第一封邮件」不是必须当场发生的完成项；但若快讯显示已停用、登录了错误帐户、或邮件全部在垃圾箱而未被发现，则还不能算做完。
5. 你能独立完成这两种维护操作中的至少一种，并实际试过入口：在快讯旁使用「修改」或「删除」；或在快讯邮件底部使用「取消订阅」。可选的 Gmail 过滤器**不是**本条完成标准的一部分。

做到以上五项，即：订阅已建立、收信帐户已对准、你知道邮件从哪里来以及如何停止，这条监控工作流就算就位。
