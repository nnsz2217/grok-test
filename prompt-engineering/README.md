# 提示词

收录高级提示词：设计方法、复杂任务、结构化输出、长任务、优化与测试，以及可以复制后改一改就能用的案例。

Skill 的目录格式和工程流程放在 [skills/](../skills/)。把提示词嵌进一条可重复流程时，流程本身放在 [automation/](../automation/)，这里保留提示词正文的写法。

## 当前内容

- [提示词的设计方法](./design-methods.md)：根据 OpenAI、Anthropic、Google 官方文档，整理怎样把任务、例子和材料写清楚，并附一份可改用的通用骨架。
- [结构化输出](./structured-output.md)：区分聊天里的格式约定和 API 里的 Structured Outputs，给出可复制的标题/JSON 写法，并说明官方数学辅导 schema。
- [学习与研究场景的可复制案例](./study-research-cases.md)：3 个改写自官方方法的模板，覆盖精读长文或论文、考试复习提纲、分步讲题。

## 以后怎么加笔记

1. 同一主题已有文件时，更新那个文件。只有独立新主题才新建文件。
2. 文末按 [笔记约定](../resources/conventions.md) 写来源链接、更新时间（Asia/Shanghai）和信息可信度。案例要链到出处；自己改写过的，写明改了什么。
3. 回到本页「当前内容」，加上相对链接和一两句这篇覆盖什么，并更新本页的更新时间。
4. 通过 Pull Request 合并，不要直接推送到 `main`。
