# AutoClaw（澳龙）

AutoClaw 是智谱（Z.ai）的通用智能体，中文下载页称之为澳龙，并写运营主体是北京智谱华章科技股份有限公司。它装在你的电脑上，按你的任务去处理文件、操作浏览器和已连接的工具，用来做调研、文档、表格或一连串网页操作。官方中文文档把它写成「装到电脑上就能干活的本地应用」，英文首页在示例旁边写着 The agent runs locally。用大白话说：你不用先租一台云电脑，也不用自己配开发环境；软件在这台电脑上执行任务。下载页同时写明，调用模型必须联网。这些页面没有解释模型文件放在哪一台机器上，本文不补架构。

它和普通聊天的差别，是官方首页写的那句：它按目标操作浏览器和本机工具，把多步工作做成可以打开的结果，而不是只回一段话。

## 能做什么

以本次打开的官网和文档为准：

- 英文首页写它跨越文件、浏览器和工具，交付报告、做过测试的软件或可直接使用的设计。首页上的角色介绍（调研、文档、代码、运营）是产品文案。页面底部的用户引言也是官网自述，不是独立评测。
- 中文常见问题里的「目标模式」：普通问答和单步任务用普通对话；你要一个可以验收的结果、并希望它持续往下做时，用目标模式。英文首页的说法一致：你给出明确结果，它自己排步骤并做到可交付。
- 中文常见问题写当前可以接入的聊天工具是飞书、企业微信、微信、钉钉和 QQ。英文首页另列了 WhatsApp、Telegram、Discord、Lark，以及 GitHub、Gmail、Google Calendar、Notion、Figma。两套名单不一样。本文只记录页面原文，没有在客户端里逐个连接。
- 中文文档首页列出的内置模型是 GLM-5.3、GLM-5-Turbo、GLM-5V-Turbo 和 Auto，并写可以再配置智谱 Coding Plan 或其他自定义模型。英文首页页头写 GLM-5.3-Flash 已上线，平台一栏写 GLM 系列和 DeepSeek 系列可切换。两处名单不完全相同，本批没有打开软件里的模型菜单。
- 下载页写安装后即有 50 多个内置技能，覆盖文档、数据、浏览器自动化等。本批没有把技能列表逐项点开。
- 高风险操作：中文常见问题建议保持「询问」。任务来自聊天工具、你没法当场批准时，建议默认「拒绝」。删除、覆盖或批量整理之前先备份。更换默认工作目录时，旧文件不会自动搬过去。

中文常见问题还提到可以把任务拆开并行的入口。那是产品里的另一个开关。本篇不讲它怎么分工。

## 怎么开始

中文安装文档写「1 分钟安装：无需租云电脑、无需配置开发环境、无技术门槛」。英文安装文档写：不用租云电脑、不用配开发环境、不需要技术背景。步骤是：

1. 按你要看的语言打开官方下载页。中文安装文档把下载地址指到 [autoclaw.z.ai/cn/download](https://autoclaw.z.ai/cn/download/)。英文安装文档指到 [autoclaw.z.ai/en/download](https://autoclaw.z.ai/en/download/)。文档站在 [autoclaw.zhipuai.cn/docs](https://autoclaw.zhipuai.cn/docs/)。中文下载页写明，桌面安装包只从这些官方按钮分发。
2. 选择和系统匹配的安装包，运行后登录。没有邀请码可以直接跳过，中文常见问题写明这不影响使用。英文安装文档的登录方式是 Continue with Zai 或 Continue with Google。中文安装文档只写登录或注册，没有在该页重复 Google 这个按钮，以你打开的语言版本为准。
3. 第一次打开后，用一句简单的话试回复，例如文档里的「用三句话介绍 AutoClaw」。再到左下角「关于」里看版本，需要的话打开自动更新。
4. 不需要编程，也不需要先安装 Python 或 Node.js。调用模型时要保持联网。

本次两个下载页列出的系统并不相同，都算已打开的原文：

- 两边都有：Windows 10 及以上（.exe）；macOS 的 Apple 芯片和 Intel 芯片各一个 .dmg，不能混装。
- 英文下载页和英文安装文档还有 Linux（x64 与 ARM64 的 AppImage）。
- 中文下载页还有银河麒麟（X86 与 ARM），以及 iOS（App Store）和 Android（官方 APK）。中文页写手机端用来查看进度、接收结果和触发部分任务，与桌面端同一账号。英文首页的平台一行写了 Windows 10+、macOS、iOS、Android，但本次英文下载页正文里看到的安装包是 Windows、macOS 和 Linux。

Windows 10 及以上在中英文下载页都写了。本批没有下载安装包。

这是本批里带有中文官网和中文文档的一个选项。功能是否对你的账号全部出现，以安装并登录后的界面为准，本文不保证每一项对每个账号都开着。

## 能力边界

- 模型调用依赖网络。公司网络或代理导致页面空白、下载失败时，官方建议换网络后重开，或在「关于」里检查更新。
- 英文首页的「本地运行」和中文文档的「本地应用」，说的是软件装在你的电脑上执行任务。它没有写成「断网也能完成模型回答」。
- 聊天工具名单、模型名单、手机端安装包，中英文页面不一致，见上文。
- 官网案例和首页引言是厂商材料。独立文章存在，但本批没有复现：
  - 《科创板日报》2026-03-10 的报道写，记者大约一分钟完成安装，并试了一次调研任务。[原文](https://www.cls.cn/detail/2308779)。报道里的模型称呼和本次文档首页的模型名单不一致，以本次官方文档为准。
  - 知乎有一篇 Windows 安装记录，作者描述首次打开会卡顿、能看到积分下降，并提醒电脑休眠或关机后任务会停。[原文](https://zhuanlan.zhihu.com/p/2019147609076414454)。这是个人帖，不是本批实测。
  - [安全内参 2026-04-13](https://www.secrss.com/articles/89363) 转述了一篇把 AutoClaw 放进对抗测试的文章。本批没有复核实验，不引用成功率。
- 早期评测里「数据完全不上传」一类说法，和本次下载页「调用模型需要联网」不是同一句话。本文采用本次官方页的说法。
