# ChatGPT

这篇说明怎样进入 ChatGPT、它适合帮大学生做什么，以及官方已经写明的限制。不展开模型原理，也不写入未核对的价格或套餐金额。ChatGPT 里的 Codex 模式不在本篇范围内，以后单独写。

## 入口

- 网页：[chatgpt.com](https://chatgpt.com)。在支持地区，有时可以先试用再注册账号。
- 手机：官方提供 iOS 和 Android 应用。
- Windows：在支持地区，用浏览器打开网页即可。另有 Windows 桌面应用，可从 Microsoft Store 安装，系统要求为 Windows 10（x64 和 arm64）17763.0 或更高；打开应用后可用 `Alt + Space` 调出随手问窗口（若快捷键已被其他软件占用，可在应用设置里改）。
- 关于谁能安装 Windows 应用，两处官方说明不完全一致：专门介绍该应用的帮助页（近期仍在更新）写的是目前面向付费方案（Plus、Team、Edu、Enterprise），而且部分网页或 macOS 功能可能还没有；2026-07-16 的 [ChatGPT 发布说明](https://help.openai.com/en/articles/6825453-chatgpt-release-notes) 则写新桌面应用已向所有方案的 macOS 和 Windows 用户开放。本篇以专门帮助页为准，并把差异记在这里。没装上桌面应用时，用网页即可。
- 开始方法：打开后在输入框写出你的问题或任务，发送即可。点 **New chat** 会开一个新对话。要保存历史，需要登录或注册账号。

## 适合什么任务

官方把日常对话和需要交成品的工作分开了：

- **Chat（对话）**：适合提问、联网查找、头脑风暴、起草或改一封消息、比较几个选项。一门课里想先把概念问清楚、把草稿写出来，从这里开始最省事。
- **ChatGPT Work**：适合你已经能说清“最后要交出什么”的较大任务，例如做一份可检查的报告、幻灯片、表格或项目计划。它能规划步骤、调用工具、给出你能预览和修改的结果。具体功能取决于方案、平台、地区、是否逐步开放，以及工作区管理员的设置。
- **Projects（项目）**：适合把同一门课、同一份作业或同一项长期任务的对话、文件和说明放在一起，避免每次重新上传资料。官方举例包括：把课堂材料放进项目，请它做学习指南或练习题。已登录用户可以使用项目，但仍受方案和工作区设置影响；能上传多少文件也因方案而异。

官方还提到：可以追加提问（同一对话里它会记住上下文）；可以请它根据文件或图片做摘要、整理或改写；可以生成图片；需要当前信息时，可以联网搜索并给出引用来源。其中“上传文件或图片做分析、摘要或转换”，帮助中心 FAQ 写明出现在带数据分析功能的付费方案里。你账号里实际能用哪些功能，以界面为准。

对非计算机专业的学生，比较稳妥的用法是：先用自己的话说明目标、关键约束和想要的格式，把第一次回复当成草稿，再用“写短一点”“给三个不同思路”“先问我几个问题再继续”来改。官方也提醒：回复写得再完整，仍可能有错，用之前要核对关键数字、姓名、日期、引文和出处。

## 限制

- **会说错，而且可能说得很有把握。** 官方称之为幻觉，例如编造定义、日期、并不存在的引用或文献。重要信息必须自己对照可靠来源，尤其是作业、引用和数据。
- **有用量限制。** 限制随方案和模型而变，也会随时间调整。Free 有基础限额，Plus / Pro 等付费方案限额更高，具体数字以账户和官方说明为准。本篇不写未核对的价格。
- **地区限制。** 必须从官方支持的国家和地区访问。截至 2026-11-25 查询，[官方支持名单](https://help.openai.com/en/articles/7947663-chatgpt-and-openai-api-supported-countries-and-territories) 未列出中国大陆、香港特别行政区和澳门特别行政区。在名单以外访问或提供访问，可能导致账号被限制或停用。本篇只记录官方名单，不讨论绕过方法。
- **不能替代专业判断。** 涉及法律、财务、医疗、安全等重大决定时，需要相应专业人士把关。
- **它不能可靠判断一段文字是不是 AI 写的**，包括“这是不是你写的这篇作文”。这类回答不能当证据。
- **功能和入口会因方案、平台、地区和逐步开放而不同。** 例如 Temporary Chat（临时对话）不会出现在历史里、不会使用或生成记忆，也不会用于训练模型，适合需要额外隐私的单次对话。
- ChatGPT 界面里还有 Codex 入口，面向偏开发的技术工作。本篇不写 Codex，以免和后续专题重复。
