# 文件、数据分析与写作块

适用产品：ChatGPT。用于带自己的材料提问、整理表格，以及在对话里直接改草稿或代码。以下为官方说明，状态为 Officially Documented。本轮没有登录实操，不能当作已经实测成功。

## 1. 提问时把文件直接附到对话里，并指明页码或范围

**用途：** 摘要、对比、抽取原句、把幻灯片改成提纲，或对录音做转写和问答。比只说“看我上次那份资料”更可控。

**操作方法：**

1. 在对话里通过 **+** → Add photos & files 附上文件，并写明要它做什么，例如“只根据第 12–18 页，列出三个可能考的概念”。
2. 常见格式包括：DOCX、PDF、TXT、Markdown、HTML、XML、JSON、YAML、Python、RTF、ODT、EML；表格 XLSX / XLS / CSV / TSV / ODS；演示 PPTX / ODP。不能直接上传 Google 的 `.gdoc`，需先导出为 PDF 或 DOCX。**这一步不需要谷歌帐户。**
3. 文档和演示的单文件上限为 512 MB；文本和文档还有每文件约 200 万 token 的上限（不适用于表格）。CSV 和表格大约 50 MB，视每行大小而定。图片每张 20 MB。
4. 上传频率官方写明：每 3 小时最多 80 个文件；免费用户每天最多 3 次上传。高峰期可能再降低。每用户共享存储上限 25 GB，每组织 100 GB。可在 Settings > Storage 查看已保存文件用量。查询日期 2026-11-25。
5. ChatGPT 可以分析 PDF 中的文字以及图表。但作为 GPT 知识库或项目文件保存的资料，处理方式与直接附到对话里不同：嵌入的图片或图表可能不会自动纳入。若要问某一张图，把 PDF 直接附到当前对话，或把图另存为 PNG、JPEG、非动画 GIF 再上传。

**可复制的提示词示例：**

```text
请只根据我刚刚附上的 PDF 第 12–18 页回答。
1. 用三条要点概括这一部分的核心概念；
2. 引用原文中最关键的两句话，并标明页码；
3. 列出我可能理解错的地方。
如果某一页看不清或找不到对应内容，直接说看不清，不要补写讲义里没有的定义。
```

**适用场景：** 复习指定章节；对比两份作业要求；从长 PDF 中抽取需要核对的原句。

**限制：** 免费方案可以使用文档、表格、演示、文本和图片上传，但受上述限额约束。扫描件或纯图片表格里的精确数值，官方提醒可能提取不可靠；需要准确数字时，改用表格或文本文件。删除对话不会自动删除已单独保存在 Library 或 Space 中的文件，需要分别删除。

**来源与可信度：** Officially Documented。[Uploading files and audio to ChatGPT](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt)。查询日期 2026-11-25。

## 2. 做表格分析前，先把数据整理成“一行一条、首行是列名”

**用途：** 让它更可靠地汇总趋势、做计算、出图表，而不是对着排版混乱的工作表猜测。

**操作方法：**

1. 在表格里使用清楚的列名，放在第一行；一行只放一条记录；列名用普通人能看懂的词语。
2. 避免：同一工作表里放多块互不相关的表、用空行空列把数据切断、把关键数值只写在图片里。
3. 上传后明确告诉它你想知道什么，以及要用哪些列、怎样分组、要哪种图。
4. 官方写明它可能在受保护的环境里用 Python 做计算，并可能把数据框显示为可交互表格。若使用了 Python，应查看它生成的代码、输出和假设后再采用结果。
5. 柱状图、折线图、饼图和散点图有时可以在静态图和交互图之间切换；其他图类型可能只提供静态图。
6. 用于数据分析的 Python 环境不能访问外部网站或 API。若分析依赖网上的新数据，需先自行下载或通过已连接且可用的来源提供。

**可复制的提示词示例：**

```text
这是一份课程问卷结果，第一行是列名，每一行是一位同学。
请先用几句话确认你看到了哪些列、一共多少行、有没有明显空值。
然后：按“年级”分组，计算“每周自学小时数”的中位数和四分位数。
再画一张柱状图比较各年级的中位数。
如果某列含义不清楚或数据不像数值，不要自行换算，先问我。
请说明你用了什么计算方法。
```

**适用场景：** 课调数据、实验记录、简单的预算或成绩汇总。

**限制：** 文件上传成功不等于能完整分析。过大、过复杂、图片过多或公式很多的表格，结果可能不完整。可指定工作表、行或列，或拆成较小文件后再问。连接 Google Drive、OneDrive、SharePoint 作为来源时，取决于方案、工作区和你对该文件的权限。**Google Drive 需要谷歌帐户。**

**来源与可信度：** Officially Documented。[Data analysis with ChatGPT](https://help.openai.com/en/articles/8437071-data-analysis-with-chatgpt)、[Uploading files and audio to ChatGPT](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt)。查询日期 2026-11-25。

## 3. 用写作块和代码块改草稿；不要再把 Canvas 当作现行功能

**用途：** 在对话里直接修改邮件、短文、文档草稿，或阅读、预览、运行受支持的代码。这是官方为写作和编程提供的当前方式。

**操作方法：**

1. 可以要求它把草稿放进可编辑的写作块，例如：“写一封给任课老师的短信，放在我可以直接改的草稿里。”
2. 视方案、设备和是否对你的帐户开放而定，写作块可能支持直接编辑、复制、让它改选中段落或全文、全屏编辑、撤销或重做、在支持时发送邮件草稿或保存到 Library。
3. 写作块支持常见格式：加粗和斜体、标题、链接、项目符号和编号列表、清单。
4. 代码通常会出现在代码块中，便于复制、查看语言、编辑、全屏查看。受支持的预览可能包括 HTML、React 组件、SVG、Mermaid 图、Vega / Vega-Lite 图表。受支持的 Python 代码块可以运行并查看控制台输出，运行环境是沙箱；若预览需要外部资源，它可能会先征求许可。
5. 对写作块和代码块的修改会在短暂延迟后随对话保存，后续追问会用最新版本。临时对话中的修改在对话结束后可能不会保留。

**不要把 Canvas 当成现在的默认功能。** 官方模型发布说明和 ChatGPT 发布说明在 2026-05-28 写道：Canvas 将不再用于 GPT-5.5 Instant 或 GPT-5.5 Thinking，写作和编程改由对话中的写作块与代码块提供；付费用户可在旧模型退场前的有限时间内继续通过旧模型使用 Canvas。随后官方又宣布从 ChatGPT 中退役 GPT-5.5（2026-10-14 的模型发布说明；该变更不影响 API）。因此，2026-11-25 查询时，不应再按旧教程去寻找现行模型上的 Canvas。若某处界面仍短暂出现历史入口，以当前模型和官方说明为准，本轮未登录核实残留入口。

**适用场景：** 反复改一封申请信或作业提纲；查看一段示例代码的预览；把笔记整理成一页可编辑文稿。

**限制：** 不是每次对话、每个方案或每台设备都有全部按钮。工作区管理员可能限制代码执行和网络访问。代码运行结果仍需你自己检查。

**来源与可信度：** Officially Documented。[Working with writing blocks and code blocks in ChatGPT](https://help.openai.com/en/articles/20001246-working-with-writing-blocks-and-code-blocks-in-chatgpt)、[Model Release Notes](https://help.openai.com/en/articles/9624314-model-release-notes)（2026-05-28 与 2026-10-14 条目）、[ChatGPT release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)。查询日期 2026-11-25。现行模型上是否完全看不到 Canvas 入口，本轮未登录，属 Unverified。

## 4. 给音频做转写时，先确认模型和入口

**用途：** 把较短的课程录音或访谈转成文字，再追问要点。

**操作方法与限制（必须一起看）：**

- 音频上传面向符合条件的付费方案和工作区，官方写明目前不在 Free 方案提供。理解与转写质量可能因语言而异。
- 在 Chat 中，官方写明应在模型选择器里选择 **GPT-6**，并在可用时选择 **Instant**，然后附上录音并要求转写。Chat 中单段录音上限约 6 分钟。
- 官方写明：GPT-6.2 在 Chat 中不支持从上传录音做音频理解或转写；Work 和 Codex 目前也不可用该转写。这些入口也许仍能附上或预览录音，但不等于能够转写。
- 音频文件最大 512 MB。支持 WAV、MP3/MPEG、OGG/OGA、仅音频的 WebM、PCM、FLAC、AAC、M4A、仅音频的 MP4。被识别为视频的 WebM / MP4 不能按音频上传。
- 更长的录音在数据分析可用时可能被分段处理，属于尽力而为，很长的文件可能超时。
- 转写可能有错，说话人识别也可能不准，重要内容须对照原录音。

**来源与可信度：** Officially Documented。[Uploading files and audio to ChatGPT](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt)。查询日期 2026-11-25。本轮未实测转写效果。
