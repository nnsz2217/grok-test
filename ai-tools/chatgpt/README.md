# ChatGPT 高级技巧

本目录整理 ChatGPT 里更细、更可操作的用法，作为 [产品总览](../ChatGPT.md) 的补充，不替换总览里的入口说明、限制和「本轮访问情况（2026-11-25，Asia/Shanghai）」。

本批对照官方帮助中心与学习文档整理，查询日期为 2026-11-25（Asia/Shanghai）。没有登录产品实操，所以功能状态只用 Officially Documented、Community Reported 或 Unverified，不标 Verified，也不声称已经实测成功。

读者若在中国大陆、香港特别行政区或澳门特别行政区，请先看总览里的地区限制：截至同一天，[官方支持名单](https://help.openai.com/en/articles/7947663-chatgpt-and-openai-api-supported-countries-and-territories) 未列出这些地区（Officially Documented）。不讨论绕过方法。

需要谷歌帐户的步骤会在各篇正文里单独标明。没有谷歌帐户时，仍可使用不依赖 Google Drive / Gmail 的项目文件、对话附件和多数网页功能。
