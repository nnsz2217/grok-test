# Skills 与办公文件

适用产品：Grok（grok.com、iOS、Android）。Skills（技能）把一套做法保存下来，之后不必每次重新解释格式或步骤；也可用内置技能生成可分享的 Office 和 PDF 文件。以下主要依据 xAI 官方新闻稿和产品文档，状态为 Officially Documented。本轮没有登录实操，不能当作已经实测成功。

## 1. 用内置技能生成 Word、幻灯片、表格或 PDF

**用途：** 直接要一份已经排过版、可以下载分享的文件，而不是只得到聊天里的纯文本。

**操作方法：**

1. 在 grok.com 或官方应用中登录。官方新闻稿写明：每个 Grok 帐户都带有 xAI 提供的内置技能，无需额外设置。
2. 用平常的话说明要什么文件、给谁用、必须包含哪些部分。官方举例包括讲习班幻灯片、带税项和付款条款的发票、月度预算表、会议投稿格式的 PDF 报告。
3. 也可以上传已有文件，请 Grok 重组、润色或扩展。
4. 官方列明可生成：Word 文档、PowerPoint 幻灯片、Excel 表格和 PDF。幻灯片方面提到完整演示文稿、视觉层级和演讲者备注；表格方面提到公式、分色区块和结构。
5. 官方写明：若你用自己的版本覆盖同名的内置技能，你的版本始终优先。

**可复制的提示词示例（改写自官方示例，不是实测结果）：**

```text
请做一份 20 分钟用的课程汇报幻灯片，主题是“为什么实验要写清楚操作步骤”。
面向同班非专业同学。请包含：问题背景、两个真实风险例子、一份可勾选的实验前清单、三道课后讨论题，以及演讲者备注。
不要编造课程数据。做好后请给我可下载的幻灯片文件。
```

```text
请根据我上传的支出记录，做一份本月预算表：
分收入、必要支出、可选支出和储蓄预测，用公式计算合计，并用颜色区分超支项目。
请生成可下载的表格文件。如果源文件里缺某一项，请标出而不是自行填数。
```

**适用场景：** 课程汇报、简历或计划书初稿、把已有提纲扩展成 PDF 报告。

**限制：**

- 新闻稿写明 Skills 在 Grok 4.3 上于 grok.com、iOS 和 Android 提供。本轮抓取的新闻稿正文没有给出发布日期，故不编造日期；页面在 2026-11-25 仍可访问。
- 新闻稿没有写清免费帐户与 SuperGrok 在生成文件次数上的差别。总览和 FAQ 说明付费方案提高限额，且自 2026 年 6 月起使用共享的每周用量池。本篇不写入未核对的次数或价格。
- 生成结果仍需你检查内容、格式和数字。官方在其他产品说明中写明，生成的图像和视频带有不能关闭的 Grok 水印；本篇不把这一图像/视频规则自动套用到 Word 或 PDF，因为新闻稿未写文件水印。
- 本轮未登录，未实际下载任何文件，输出质量为 Unverified。

**来源与可信度：** Officially Documented。[Skills in web, iOS, and Android](https://x.ai/news/grok-skills)、[Welcome to Grok](https://docs.x.ai/grok/overview)、[FAQ - Grok Website / Apps](https://docs.x.ai/grok/faq)。查询日期 2026-11-25。

## 2. 把反复使用的流程存成自己的技能

**用途：** 把已经调顺的格式、评分标准或写作步骤保存下来，以后直接调用，不必每次重新粘贴长说明。

**操作方法（官方新闻稿级说明，不是逐步界面手册）：**

1. 官方写明，创建技能可以：在对话里描述、上传文件，或从零写一份。
2. 若已经花时间调好了格式或流程，可以直接请 Grok 把刚才学到的做法存成技能，以免再解释一遍。
3. 你自定义的版本若与内置技能同名，会覆盖内置版本并优先使用。

**可复制的提示词示例：**

```text
请把刚才我们一起确定的“每周文献笔记”格式保存为我的技能。
以后只要我上传一篇 PDF，就按这个结构输出：
研究问题、方法、三条发现、局限、我还没核对的引用。
用简体中文。不要补充 PDF 里没有的文献。
请告诉我这个技能叫什么，以及我下次怎样提起它。
```

**适用场景：** 固定的读书笔记格式、每次都相同的作业自查清单、常用的邮件或简历结构。

**限制：** 新闻稿没有提供与 ChatGPT / Codex `SKILL.md` 目录结构相当的消费端文件格式说明，也没有写明技能在个人帐户中如何分享。团队工作区的技能分享策略见商业文档，默认从 Private 开始，不能据此推断个人免费帐户的分享能力。本轮未登录创建技能，保存后是否在所有对话中自动生效，属 Unverified。不要把 Grok Bot 或 Grok Build 的技能文档直接当成 grok.com 的操作步骤。

**来源与可信度：** 创建方式为 Officially Documented（新闻稿概述）。逐步菜单、分享和个人帐户配额未在消费端手册中找到，相关细节为 Unverified。[Skills in web, iOS, and Android](https://x.ai/news/grok-skills)、[License & User Management](https://docs.x.ai/grok/management)。查询日期 2026-11-25。
