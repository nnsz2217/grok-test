# Grok 高级技巧

本目录整理 grok.com 与官方 iOS / Android 应用里更细的用法，作为 [产品总览](../Grok.md) 的补充，不替换总览里的入口说明、限制和「本轮访问情况（2026-11-25，Asia/Shanghai）」。本批不以 X 平台里的 Grok 或 Grok Bot 为操作对象。

本批对照 xAI 官方文档、产品页和官方新闻稿整理，查询日期为 2026-11-25（Asia/Shanghai）。没有登录产品实操，所以功能状态只用 Officially Documented、Community Reported 或 Unverified，不标 Verified，也不声称已经实测成功。

登录可以用 X 账号或邮箱等，不一定需要谷歌帐户。只有在连接 Gmail、Google Calendar 或 Google Drive 时才必须有谷歌帐户，各篇会单独标明。
