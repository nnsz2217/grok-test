# 搜索、深度推理与多智能体

适用产品：Grok 消费端。按问题类型选择搜索、更长的推理，或（在付费方案中）多智能体，而不是默认用同一种模式处理所有问题。以下以 2026-11-25 仍可访问的官方产品页和概览为准，状态为 Officially Documented。本轮没有登录切换模式，不能当作已经实测成功。

## 1. 先分清三种现行能力，再决定是否需要 SuperGrok 的多智能体

**用途：** 查正在发生的事情时用实时搜索；需要可跟随的逐步思考时用深度推理；特别复杂、要把问题拆开平行处理时，再考虑多智能体。

**官方产品页在 2026-11-25 列出的相关能力：**

- **Search（搜索）：** 实时搜索网页和 X，回答带有来源引用，并可追问。适合要“现在”的信息，而不是只依赖训练数据。
- **Deep reasoning（深度推理）：** 逐步思考，并且这些步骤可以跟随和核对。产品页引导用户在对话中切换搜索、推理、语音或图像等模式。
- **Multi-agent（多智能体）：** 多个代理并行处理子问题，各自展示工作过程，再合并成一个带引用的回答。产品页写明：免费可在网页和应用中试用；升级到 SuperGrok 可获得更高限额、优先访问和多智能体。

**可复制的提示词示例：**

```text
请先搜索 2026 年关于“大学生使用生成式 AI 写作业”的公开政策或大学通知。
只列出带链接的来源，并注明日期。
如果不同学校规定冲突，请并列写出，不要合成一个并不存在的统一政策。
```

```text
这是一道需要多步计算的应用题（题目见下）。
请用深度推理，逐步写出每一步在算什么、用了哪个已知量。
最后再给出答案。如果某一步缺少条件，停下来问我，不要自行补数。
```

```text
请用多智能体（如果我的帐户可以使用）研究：开卷考试和闭卷考试对记忆保持的影响。
请拆成：支持开卷的证据、支持闭卷的证据、研究方法上的常见缺陷。
每条结论都要带来源。最后合并成一份简报，并标出仍然无法下结论的部分。
```

**适用场景：** 查最近的通知或新闻用搜索；解多步题或要求它展示推理过程时用深度推理；综述类、需要同时比较多条线索的大问题，再考虑多智能体。

**限制：**

- 产品页是功能概述，不是逐步按钮手册。本轮未登录，无法核对 grok.com 上按钮的准确名称、位置，以及免费帐户能看到哪些开关，属 Unverified。
- 多智能体官方写明随 SuperGrok 提供；不要假定免费帐户一定能打开。未核对手表价，故不写入金额。
- 即使带有引用，仍须打开原文核对，尤其是作业和正式引用。
- **不要把 DeepSearch 当作 2026-11-25 的现行功能名来教。** 较早的 Grok 3 材料中曾出现 DeepSearch 按钮（例如 xAI 开源提示词仓库中的产品说明）。在本次查询中，现行产品页和消费端概览列出的是实时搜索、深度推理和多智能体，而不是 DeepSearch。若你在旧教程或旧界面截图里看到 DeepSearch，应对照当前页面，不要把过时名称写成现行操作。

**来源与可信度：** 现行能力划分为 Officially Documented，见 [Grok 产品页](https://x.ai/grok)、[Welcome to Grok](https://docs.x.ai/grok/overview)。界面按钮实况为 Unverified。DeepSearch 作为现行名称：未在 2026-11-25 的产品页/概览中出现，故不收录为现行技巧。查询日期 2026-11-25。
