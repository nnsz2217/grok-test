# 文件上传与提问

适用产品：Grok（grok.com、iOS、Android）。用于分析、摘取信息和做摘要，也可一次附上多种材料一起讨论。以下为官方 FAQ 说明，状态为 Officially Documented。本轮没有登录完成上传问答，不能当作已经实测成功。总览里 2026-11-25 的未登录访问记录仍然有效：未登录点击附件会先出现登录窗口。

## 1. 一次附上相关材料，并指明页码或对比对象

**用途：** 比较两份讲义、从长 PDF 里抽取某一页的要点，或把文档、表格和图片放在一起问。

**操作方法：**

1. 登录后，在任一对话中点击输入框旁的 **+**，从设备选择文件；网页上也支持拖放。
2. 一条消息可以附上多个文件。官方写明：网页一次大约最多 100 个文件，Android 最多 20 个，iOS 支持多个文件。
3. 常见类型包括：PDF、DOCX、TXT、CSV、XLSX、PPTX、HTML、XML、JSON、Markdown、LaTeX、ODT、RTF，以及代码文件；图片 JPEG / PNG / WebP / HEIC / BMP（GIF 和 SVG 因平台而异）；音频 MP3、WAV、M4A、OGG、FLAC、AAC；视频 MP4、MOV。网页往往对文档类型支持更全。
4. 多数文件（文档、图片、代码、音频）单文件上限约 150 MB。很大的文件可能会被分段或摘要处理。超过限制时，界面会给出明确错误提示。限额可能因平台或订阅略有差异。
5. 官方给出的效果提示：
   - 需要细致看图时，优先使用高分辨率图片（官方建议最好不低于约 1000×1000 像素）。
   - 对超过 100 页的 PDF，Grok 会侧重文字和关键视觉内容；提问时请使用实际页码。
   - 极长文档可拆成较小部分再上传。
   - 混合上传（例如 TXT + PDF + PPTX + 图片 + 代码）可以一起使用。

**可复制的提示词示例（改写自官方示例风格，不是实测结果）：**

```text
我上传了两份 DOCX 课程说明。请只根据文件内容对比：
1. 评分构成有何不同；
2. 截止日期和提交方式；
3. 相互冲突或写得不清楚的地方。
请标明你依据的是哪一份文件的哪一节。如果某项找不到，直接写“文件里没写”，不要补全。
```

```text
请看这份 PDF 第 14–16 页的图和正文。
先用自己的话描述这几页在讲什么，再列出三个可能的考试要点。
不要使用这几页之外的内容。
```

官方 FAQ 中的示例还包括：“Describe the image and fix the code in the attached file.” 以及 “Compare these two DOCX files.”

**适用场景：** 对比两份作业要求；复习指定页码；把实验记录表和一段说明文字一起分析。

**限制：**

- 官方写明：多数文档可以抽取文字，但非 PDF 文件中的嵌入图片可能不会按视觉方式处理。
- 部分音频和视频能够上传，但转写质量不稳定。
- 删除的对话和文件会在标准保留期内从系统中移除，除非因法律、合规或安全需要保留更久。
- 上传失败时，官方建议：不支持的类型可转为 PDF 或 TXT，或换一个平台再试；失败时检查文件大小；“附件无法加载”常常与平台有关，可换平台或转换格式。
- 网页端可到 grok.com/files 删除内容以腾出空间；更多数据控制在 Profile → Settings → Data Controls。
