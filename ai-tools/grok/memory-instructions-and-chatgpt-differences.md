# 记忆、自定义指令及与 ChatGPT 的差异

适用产品：Grok 消费端，并与 ChatGPT 做对照，避免把其中一个产品的旧教程套到另一个上。产品能力以官方页面为准；两边的逐步手册完整程度并不相同。本轮没有登录实操，不能当作已经实测成功。

## 1. 产品页已列出跨对话记忆和自定义指令，但消费端手册较简略

**用途：** 让 Grok 记住你的偏好和过去的对话要点，或事先说明希望它怎样回答，减少重复交代。

**截至 2026-11-25 可核对的官方表述：**

- [Grok 产品页](https://x.ai/grok) 将 **Memory across chats**（跨对话记忆）列为能力之一，说明它会记住你的偏好和以往对话。
- 同一页列出 **Custom instructions**（自定义指令），用于按你的风格和需要调整回答。
- 同一页还列出 **Canvas for writing**（用于写作的画布）以及可分享的对话链接。

官方消费端 FAQ 和概览详细写了文件上传、用量和连接器，但本轮没有找到与 ChatGPT 帮助中心同等详细的“如何打开记忆、如何编辑已记住的内容、自定义指令写在哪一屏”的手册。因此：

- 上述能力的存在为 Officially Documented（产品页）。
- 具体点击路径、记忆是否可逐条删除、写作画布与 ChatGPT 已退出的 Canvas 是否同类，均为 Unverified，本篇不编写未核对的菜单步骤。

若你在已登录界面的设置里看到记忆或自定义指令，可以先写一条简短、可检查的偏好，例如语言、解释深度、以及“不要编造引用”。把设置前的原文和设置后的效果自行记下；在官方补全手册或完成实测前，不要把个人观察写成已核对的通用步骤。

**可复制的指令草稿（供粘贴到官方提供的自定义指令栏，若你的帐户有该栏；不是实测结果）：**

```text
请默认使用简体中文。先给结论或步骤，再补必要解释。
涉及事实、数据和文献时，请给出可打开的来源；没有来源就明确说不确定。
不要为了完整而编造书名、链接或页码。
```

**适用场景：** 希望它长期用简体中文、按你的学习程度解释；或希望减少重复说明。

**限制：** 产品页不是操作手册。不要把 ChatGPT 的 Settings → Personalization 路径直接写成 Grok 的步骤。也不要假设 Grok 的写作画布仍可用，就推论 ChatGPT Canvas 也还在——ChatGPT 侧的 Canvas 已从现行模型退出，见 ChatGPT 的写作块笔记。

**来源与可信度：** 能力存在为 Officially Documented，见 [Grok 产品页](https://x.ai/grok)。操作细节为 Unverified。查询日期 2026-11-25。

## 2. 和 ChatGPT 对照时，先记住这些已经能核对的差异

**用途：** 选工具或阅读教程时，避免混用名称、过时功能和并不相同的限制。

**已能对照官方材料核对的差异（查询日期 2026-11-25）：**

| 主题 | Grok | ChatGPT |
| --- | --- | --- |
| 推荐入口 | grok.com，建议 Chrome / Chromium；Windows 以浏览器为主，无单独消费端桌面应用说明 | chatgpt.com；另有官方 Windows 桌面应用（适用方案以专门帮助页为准） |
| 地区 | 官方只做原则说明，未在消费端 FAQ / 概览中公布完整国家名单 | 有官方支持国家和地区名单；截至 2026-11-25 未列出中国大陆、香港特别行政区和澳门特别行政区 |
| 登录 | 可用 X、邮箱等；不是必须谷歌帐户 | 按 OpenAI 帐户体系；部分连接应用才需要谷歌帐户 |
| 文件上传 | 官方写明网页约 100 个文件、单文件约 150 MB 等 | 另有每 3 小时 80 个文件、免费用户每天 3 次、项目文件数量分档等规定 |
| 可重复工作流 | Skills（官方新闻稿：内置办公技能，可自建）；团队文档还涉及项目与技能分享 | 项目说明、插件；自定义 GPT 计划于 2026-12-11 退役，个人帐户不能新建 GPT |
| 深度工作 | 产品页：搜索、深度推理、多智能体（多智能体随 SuperGrok） | 深度研究、Work；代理模式已退出 |
| 写作界面 | 产品页仍列出 Canvas for writing | Canvas 已从 GPT-5.5 起退出，改由写作块和代码块提供；随后 GPT-5.5 也已从 ChatGPT 退役 |
| 生成图像 / 视频 | 官方写明带 Grok 水印且不能关闭 | 以 ChatGPT Images 等现行说明为准，不在此展开 |
| 用量 | 付费为 SuperGrok；2026 年 6 月起为共享每周用量池 | 随 Chat / Work / Codex 和模型分档，规则不同 |

表中每一项都应回到对应笔记和总览查看出处，不要当成可以脱离原文的完整对照手册。两边都可能继续改产品，本表只反映查询当日已核对的官方表述。

**适用场景：** 阅读 2024–2025 年的旧教程时先核对功能是否还在；决定这门课的资料放在哪一侧的项目或技能里。

**限制：** 这不是评测，也没有做同一任务的双边实测。价格未核对，故不写入金额。Grok 完整地区名单官方未公布，不能提前假定某一地区一定可用或一定不可用。

**来源与可信度：** Officially Documented（各项分别来自两边官方文档/产品页，已在本库对应笔记列出）。作为对照表的编排是本库整理，不是官方发布的对比页。查询日期 2026-11-25。
