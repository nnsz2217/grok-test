# Grok

这篇说明怎样进入 Grok（SpaceXSI 的对话助手）、它适合帮大学生做什么，以及官方已经写明的限制。不展开模型原理，也不写入未核对的套餐金额。本篇以 grok.com 和官方 iOS / Android 应用为主；X 平台上的 Grok 使用另一套条款，这里只作入口提示，不做展开。也不评测 Grok Bot。

## 入口

- 网页：[grok.com](https://grok.com)。官方建议使用常规的 Chrome 或基于 Chromium 的浏览器（例如 Edge）。部分用户在 grok.x.ai 或其他地址会碰到功能缺失（官方举例包括 Projects）。
- 手机：官方提供 iOS 和 Android 应用。登录一次后，对话、设置和订阅会在网页与应用之间同步。
- 登录：可用 X 账号或邮箱等登录。若要把 X 的登录或订阅权益关联过来，可在网页 Settings → Account 里连接 X 账号；登录方式也可以在 [accounts.x.ai](https://accounts.x.ai) 管理。请始终用同一个账号，避免误以为付了两次费。
- Windows：官方消费端入口是网页和 iOS / Android 应用，没有单独列为 Windows 桌面应用。在 Windows 上请用浏览器打开 grok.com。
- 也在 X 平台提供 Grok。若你用的是 X 里的 Grok，请以 X 帮助中心和 X 的条款为准，与 grok.com 不是同一套说明。
- 年龄：Grok 不面向 13 岁以下用户；使用前须确认已满 13 岁。13 至 17 岁须获得父母或法定监护人同意，并由其同意服务条款。
- 开始方法：打开后直接开始对话即可。上传文件时，点击输入框旁的 **+**，在网页上也支持拖放。

## 适合什么任务

官方概述里，Grok 适合这些日常用法：

- **对话：** 提问、头脑风暴、写作，以及把问题来回讨论清楚。
- **看你自己的材料：** 在网页、iOS 和 Android 上都可以上传文件，用于分析、摘取信息和做摘要。官方写明常见文档、数据表、代码、图片、音频等都在支持范围内；网页往往对文档类型支持更全。网页一次大约最多 100 个文件，Android 最多 20 个，iOS 支持多个文件；多数文件（文档、图片、代码、音频）单文件上限约 150 MB。很大的文件可能会被分段或摘要处理。超过限制时，界面会给出明确错误提示。
- **生成图像和视频、使用语音：** 官方把这些列为可以直接做的事。生成内容会带有 Grok 水印，没有关闭选项；去除、改动或遮挡水印及其他来源标记，违反可接受使用政策。
- **连接已有工具：** 可以把邮箱、文件、日历等连进对话。本篇只记录官方有这一入口，不评测各个连接器。

对大学生来说，比较直接的用法是：把讲义或 PDF 从 **+** 加进去，说明你要它做什么（例如“按章节列出我需要记住的概念，并出 5 道自测题”）；需要写草稿或讨论思路时，直接在对话里说清对象、篇幅和语气。官方也提示，网页端请用 Chrome / Edge，以免部分功能看不到。

## 限制

- **有免费档，也有付费档，并且都有用量限制。** 官方写明 Grok 可以免费开始；付费的 SuperGrok 方案会提高限额，并在各产品中解锁更多能力。付费用量从 2026 年 6 月起改为共享的每周用量池，可在聊天、图像和视频生成、语音等产品之间自行分配；不同产品消耗的计算量不同，生成高质量视频或较长的编程任务会比普通聊天消耗更多。用尽当周付费额度后，付费功能会暂停，直到额度重置；此时仍可使用免费档在 Chat 和 Voice 上的限额（与每周付费池分开计算、单独重置）。也可以购买额外用量额度、升级方案，或打开自动补额。额外用量额度目前只能在网页购买，移动端内购尚未开放。具体金额和各档配额未在本篇核对，故不写入数字。
- **查看用量：** 在网页或手机的 Settings → Usage 可以看到已用百分比、分产品占比、每周重置时间，以及额外额度余额（如有）。
- **地区可用性官方只做了原则说明。** [Consumer FAQs](https://x.ai/legal/faq) 写明：视所在地区而定，可能提供有限的免费使用，以及解锁完整功能的付费方案。官方没有在该页或当前 Grok 概览/FAQ 中公布完整国家或地区名单。因此，某一地区能否注册或付费，只能以打开 grok.com 或应用后的实际页面为准，不能提前假定一定可用。
- **Windows 没有官方独立桌面应用。** 请用浏览器访问 grok.com。
- **生成的图像和视频带水印，不能关闭。**
- 本篇不评测 Grok Bot，也不把 X 平台里的 Grok 当成同一个产品来写操作步骤。
