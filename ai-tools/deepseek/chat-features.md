# 网页与 App 的对话功能

适用产品：DeepSeek 网页版（chat.deepseek.com）和官方 App。用于日常提问、带着资料复习，以及需要上网核对的问题。以下为官方说明，状态为 Officially Documented。本轮没有登录实操，不能当作已经实测成功。界面上的按钮文案以登录后的实际页面为准（Unverified）。

官方在 2026-11-13 的更新中写明：在 DeepSeek App（包括网页版）里，网页搜索、文件输入、网址阅读、语音互动和安全审核与模型推理一起构成用户熟悉的对话体验。API 文档在介绍对应接口时，也反复写这些能力和网页/App 中的用法是同一类功能。

## 1. 先按任务开关思考模式，再决定要不要联网

**用途：** 简单问题少等待，较难或需要当前信息的问题再打开思考和搜索，避免一上来就用最慢的组合。

**操作方法（以官方对产品能力的命名为准）：**

1. 在网页或官方 App 中打开一个新对话，用自己的话写清题目、已知条件和你希望的格式。
2. **思考模式：** 模型会先给出一段思维链，再给最终答案，官方说这有助于提高最终答案的准确性。在 API 中，思考模式默认开启，默认强度为 `high`；网页/App 里如何开关，官方没有给出与 ChatGPT 帮助中心同等详细的逐步手册，请以界面为准（本轮未登录，属 Unverified）。
3. **网页搜索：** 用户协议写明，开启「联网搜索」后，产品会按你的输入先检索互联网公开信息，再根据检索结果生成内容。API 文档把「思考关闭 + 启用搜索工具」对应为普通网页搜索，回答可带引用。
4. **深度思考搜索：** API 文档把「思考开启 + 启用搜索工具」对应为深度思考搜索：模型可在多步推理中自行搜索、打开页面，并在页面中查找文字，类似 DeepSeek Chat 中的深度思考搜索；官方写明这一过程大约最多约 20 次工具调用。
5. 如果问题不依赖网上的新信息（例如只问已上传讲义里的定义），不要打开搜索，以免答案混入材料之外的内容。

**可复制的提示词示例：**

```text
请根据你检索到的公开资料，回答下面这个问题，并列出主要来源的标题和链接。
问题：2026 年诺贝尔经济学奖的得主是谁？主要贡献如何概括？
要求：
1. 先说明检索到了哪些来源；
2. 如果来源互相矛盾或不够权威，直接写出来，不要选一个听起来最完整的说法；
3. 不要编造链接或论文题目。
```

**适用场景：** 概念题先关搜索、需要时再开思考；时事、政策、新发表的数据再开联网；既要推理又要核对出处时，再用深度思考搜索。

**限制：** 检索到的公开信息仍可能过时或不准确。官方没有在本批找到的公开文档里保证引用完整或不会遗漏对立来源。深度思考搜索会花更多时间和输出；在 API 中，自 2026-11-18 12:00（北京时间）起，模型调用时触发的服务端搜索、网页抓取本身不再单独计费，但工具返回内容会进入上下文，按模型 token 计费。网页/App 是否单独计费，官方公开价目页针对的是 API，不要把 API 规则直接写成网页账单。

**来源与可信度：** Officially Documented。[构建 Chatbot](https://api-docs.deepseek.com/zh-cn/guides/build_a_chatbot/)、[联网工具](https://api-docs.deepseek.com/zh-cn/guides/web_tools/)、[思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)、[DeepSeek 用户协议](https://cdn.deepseek.com/policies/zh-CN/deepseek-terms-of-use.html)、[更新日志 2026-11-13](https://api-docs.deepseek.com/updates/)。界面开关位置为 Unverified。查询日期 2026-11-25。

## 2. 把讲义或论文直接上传，并限定只根据材料回答

**用途：** 摘要指定章节、抽取原句、对照作业要求，减少模型用训练知识“补写”讲义里没有的定义。

**操作方法：**

1. 在网页或 App 的对话中上传文件，并写明页码或范围，例如“只根据第 12–18 页”。
2. 官方文件解析指南写明，这种方式与 DeepSeek 网页端上传文件一致，常见类型包括 PDF、Word（DOC / DOCX）、PowerPoint（PPT / PPTX）和图片（PNG、JPEG、WebP、GIF、BMP、TIFF 等）。
3. 若文档里的图很重要（趋势图、示意图），需要模型“看见”图，而不仅仅提取文字。官方把两种解析目的写得很清楚：只要文字时用文本识别；需要结合图表时用富布局识别。网页端具体选项名称以界面为准（未登录，Unverified）。
4. 问完后核对应答里的页码和原句，不要直接把生成内容当作引用。

**可复制的提示词示例：**

```text
请只根据我刚刚上传的 PDF 第 12–18 页回答。
1. 用三条要点概括这一部分的核心概念；
2. 引用原文中最关键的两句话，并标明页码；
3. 列出我可能理解错的地方。
如果某一页看不清、或材料里没有对应内容，直接说找不到，不要补写讲义里没有的定义。
```

**适用场景：** 复习指定章节；对比两份作业要求；从长 PDF 中抽出需要再去教材里核对的原句。

**限制：** 本批能核对到的定量限制，主要写在 API 文件解析文档中，例如：需解析的文档单个不超过 100 MiB、最多 1,000 页；每个请求最多引用 20 个文档，文档文字合计不超过 8 MiB；多轮中已引用文档会完整保留在上下文，超长时返回错误而不是静默截断。这些是 API 规则。网页/App 是否采用完全相同的上限，官方只确认“与网页端上传文件一致”这一产品能力，本轮未登录核实网页端的实际限制，故网页端具体大小和页数上限为 Unverified。设有打开密码的文件，API 会无法解析。不保证文档中的每一张图都能被识别出来。

**来源与可信度：** 产品能力与 API 限制为 Officially Documented。[文件解析](https://api-docs.deepseek.com/zh-cn/guides/document_parsing/)、[构建 Chatbot](https://api-docs.deepseek.com/zh-cn/guides/build_a_chatbot/)。网页端具体按钮和限额为 Unverified。查询日期 2026-11-25。

## 3. 需要它阅读某个链接时，把网址直接放进问题里

**用途：** 让模型先抓取你给出的页面，再结合页面内容回答，而不是只靠记忆或笼统搜索。

**操作方法：**

1. 在问题中粘贴完整网址，并说明要它根据该页做什么，例如“根据这个课程通知，列出截止日期和提交方式”。
2. 官方把这一能力称为网址阅读（URL reading）：模型检测用户消息中的链接，抓取页面后再结合内容作答。API 中通过启用 `deepseek_read_url` 使用；网页/App 已包含该能力。
3. 这和深度思考搜索里“打开它自己搜到的页面”不是同一件事：前者处理你贴出的链接，后者处理搜索过程中找到的页面。

**适用场景：** 课程通知、公开的方法说明、需要对照某一篇公开网页的作业要求。

**限制：** 未公开的、需登录才能看的页面，或机器人无法抓取的页面，可能读不到。抓取到的内容仍需你自己核对。本轮未实测抓取效果。

**来源与可信度：** Officially Documented。[构建 Chatbot](https://api-docs.deepseek.com/zh-cn/guides/build_a_chatbot/)、[联网工具](https://api-docs.deepseek.com/zh-cn/guides/web_tools/)。网页界面细节为 Unverified。查询日期 2026-11-25。
