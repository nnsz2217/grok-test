# API 价格与省钱方法

适用产品：DeepSeek 官方 API。用于估算学习场景下的调用成本，并按官方规则降低费用。以下价格均来自 2026-11-25（Asia/Shanghai）核对的官方价目页，状态为 Officially Documented。价格会调整，使用前应再次打开原文。本轮没有实际扣费，下面的算术示例只是按官方单价计算，不是实测账单，不能标为 Verified。

**请以 API 文档价目页为准，不要用官网营销页上的数字。** 同日打开的 [API 开放平台介绍页](https://www.deepseek.com/platform/) 仍展示另一组金额（例如把 Flash 输出写成每百万 tokens 2 元，并把峰谷定价写为“预计 7 月中旬开始”）。这与已经生效的官方 API 价目不符，本篇视为过时展示，不以它报价。

## 1. 先看懂计价单位和高峰时段，再选模型

**用途：** 知道自己大概会花多少钱，并尽量避开高峰单价。

官方按百万 tokens 计价。Token 是模型处理文本的最小单位，可能是一个词、数字或标点。费用 = 用量 × 对应单价。下面同时给出中文价目页的人民币价格，以及英文价目页的美元价格；两者都是官方页面，结算币种以你账户实际币种为准（余额接口可返回 `CNY` 或 `USD`）。

**高峰时段（官方，已换算为北京时间）：** 周一至周五（不含中国法定节假日）9:00–12:00、14:00–18:00。其余时间，包括周末和中国法定节假日全天，为空闲时段。空闲时段价格是高峰时段的一半。英文页用 UTC 表述为 01:00–04:00 与 06:00–10:00（周一至周五，不含中国法定节假日），与上面的北京时间一致。

**模型单价（每百万 tokens，查询日期 2026-11-25）：**

| 项目 | deepseek-flash 空闲 | deepseek-flash 高峰 | deepseek-v4-pro 空闲 | deepseek-v4-pro 高峰 |
| --- | --- | --- | --- | --- |
| 输入（缓存命中） | 0.02 元 / $0.003 | 0.04 元 / $0.006 | 0.15 元 / $0.022 | 0.30 元 / $0.044 |
| 输入（缓存未命中） | 1 元 / $0.15 | 2 元 / $0.3 | 4.5 元 / $0.66 | 9.0 元 / $1.32 |
| 输出 | 4 元 / $0.6 | 8 元 / $1.2 | 13.5 元 / $1.98 | 27.0 元 / $3.96 |

上下文长度均为 1M，最大输出 384K。Flash 支持图像理解，Pro 不支持。并发限制：Flash 2500，Pro 500，按账号计。

**按官方单价做的算术示例（不是实测账单）：** 在空闲时段用 `deepseek-flash`，若一次请求输入 2,000 tokens 且全部未命中缓存、输出 500 tokens（均不含思考过程的额外输出），则估算为  
输入 \(2000/1{,}000{,}000 × 1\) 元 + 输出 \(500/1{,}000{,}000 × 4\) 元 = 0.002 + 0.002 = **0.004 元**。  
若同样用量发生在高峰时段，则为 0.004 + 0.004 = **0.008 元**。开启思考后，输出（含思维链）通常更长，费用会高于这个示例。本轮没有账单可以对照。

**适用场景：** 个人学习、小作业问答。大多数情况下，空闲时段的 Flash 单价已经很低；没有特殊理由不必默认改用 Pro。

**限制：** 产品价格可能变动，DeepSeek 保留修改权利。不要把本表抄到几个月后仍当现行价。思维链、工具返回内容都会占用 token。英文页 Flash 高峰未命中输入写为 `$0.3`，其余金额与人民币页并列于上表，引用时请打开原文核对。

**来源与可信度：** Officially Documented。[模型 & 价格（中文）](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[Models & Pricing（英文）](https://api-docs.deepseek.com/quick_start/pricing/)、[查询余额](https://api-docs.deepseek.com/zh-cn/api/get-user-balance)。介绍页金额不采用。算术示例不是实测。查询日期 2026-11-25。

## 2. 把长期不变的说明和材料放在对话最前面，让缓存更容易命中

**用途：** 缓存命中的输入单价远低于未命中（例如空闲时段 Flash 为 0.02 元对 1 元，每百万 tokens）。反复针对同一份讲义提问时，这是最主要的省钱方法。

**操作方法（官方规则的可操作理解）：**

1. 上下文硬盘缓存对所有用户默认开启，不必改代码去“打开缓存”。
2. 后续请求只有在前缀与已落盘的缓存单元**完整匹配**时才会命中。因此：系统说明、整份材料、固定要求应放在消息最前面，后面只追加新问题；不要在材料前面插入每次都变化的日期、随机编号或把材料顺序打乱。
3. 官方例一：第二轮在第一轮的完整对话后面继续提问，可以命中上一轮的前缀。
4. 官方例二：两次提问都带同一份长材料，但第一句用户问题和材料的拼接方式不同，前两次可能都未命中；系统检测到公共前缀并落盘后，第三次带同一份材料的提问才可能命中。所以对同一份长文档做多轮问答时，应保持“系统说明 + 同一份材料”这部分完全一致，只改最后的问题。
5. 在 API 返回的 `usage` 里查看 `prompt_cache_hit_tokens` 和 `prompt_cache_miss_tokens`，用来判断有没有命中。
6. 缓存是尽力而为，不保证每次命中。缓存构建为秒级；不再使用后通常在几小时到几天内被清空。缓存只加速和降价输入前缀，不保证两次输出一字不差。

**适用场景：** 同一份课程 PDF 或同一套系统说明下，连续问很多道不同的题。

**限制：** 本批未实测命中率。若每次都把整份材料重新改写或放在不同位置，可能几乎得不到命中价。

**来源与可信度：** Officially Documented。[上下文硬盘缓存](https://api-docs.deepseek.com/zh-cn/guides/kv_cache/)、[模型 & 价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。命中效果为 Unverified。查询日期 2026-11-25。

## 3. 能在空闲时段做的请求就避开高峰；并分清模型费用和附加接口费用

**用途：** 不急的整理、批量试提示词，放到晚上、周末或节假日，单价直接减半；同时避免把“搜索、解析文件”的计费规则弄混。

**操作方法：**

1. 查询北京时间，避开工作日 9:00–12:00 和 14:00–18:00（中国法定节假日全天仍为空闲）。需要当场得到答案的提问不必硬等。
2. 简单问题关闭思考或改用 `low`，减少输出 token，见 [模型与思考强度怎么选](./model-selection.md)。
3. **模型调用时的服务端搜索 / 网页抓取：** 自 2026-11-18 12:00（北京时间）起，调用模型时触发的服务端搜索、网页抓取，**工具调用本身不再计费**；工具返回结果会拼进上下文，按模型 token 计费。触发条件包括联网工具、Anthropic API 的 `web_search`、Responses API 的 `web_search`。
4. **独立的 Search API 与 Fetch API**（按次计费，不是上面那种随模型触发的工具）：每 1,000 次成功请求 5 元 / $0.75。不要把这两类搜索的账单混为一谈。
5. **文件解析与 OCR：** 每 1,000 页 1.5 元 / $0.225。解析成功时按页数一次性计费；之后在对话中引用该文件不再收解析费，但会按拼入上下文的输入 token 计费。纯文本、表格（XLSX / XLS）和电子书（EPUB / MOBI）以 `user_data` 上传时官方写明不计解析费（不支持 AZW3 和带 DRM 的电子书）。
6. **语音：** 价目页另列语音合成（每 10,000 字符刊例价 3 元、限时 5 折 1.5 元）和语音识别（每小时刊例价 0.78 元、限时 5 折 0.39 元）。这是限时折扣，是否仍有效以当天价目页为准，本篇不把折扣当成永久定价。
7. 扣费顺序：赠送余额优先于充值余额。

**适用场景：** 不急的资料整理和提示词试验；上传一份讲义后多次提问（解析费只在成功解析时付一次）。

**限制：** 本篇不提供自动定时发请求的脚本。独立 Search/Fetch 的按次费用与模型内工具的新规则不同，引用时要看你实际调用的是哪一种接口。限时语音折扣可能结束，未在本轮核对其截止日期。

**来源与可信度：** Officially Documented。[模型 & 价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[文件解析](https://api-docs.deepseek.com/zh-cn/guides/document_parsing/)。限时折扣的截止日期未知。查询日期 2026-11-25。
